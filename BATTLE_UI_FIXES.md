# Исправления по скриншотам — 29 сентября 2026

1. **Живой противник зачёркнут.** Нативный клиент определяет гибель игрока по
   зарегистрированным моделям бойцов, а не по списку участников. Ранее скрытые
   бойцы оставались зарегистрированы только в шахте. Теперь во всех игровых
   режимах скрытый противник представлен моделью в позиции 255/255 с HP 1/0.
   Реальное положение, перемещение и текущее здоровье не отправляются.
2. **Оружие и броня из контейнера.** Общая проверка обмена silver.dll отвергала
   обычную экипировку с прочностью ещё до отправки запроса 40. Клиентский патч
   разрешает немаркированные предметы только при активном боевом контексте и
   режиме наземного контейнера (47). Городской обмен, обмен между бойцами и
   маркированная экипировка проходят прежнюю проверку. Сервер по-прежнему
   проверяет владельца хода, расстояние, открытый контейнер, количество,
   вместимость и актуальность инвентаря.
3. **Интерфейс после пропуска хода.** Сервер уже запрещал действия, но оставлял
   прежние ОД в модели. Завершение и тайм-аут теперь обнуляют ОД живых бойцов и
   отправляют статус 4E перед 39. Бюджет следующего хода сохраняется; состояние
   погибших не изменяется. Переподключение получает уже обнулённую модель.
4. **Пустой аукцион.** Клиент начинает поиск со страницы 1, сервер ранее считал
   её второй страницей. Исправлены срезы выдачи и номер ответа; переход на
   следующие страницы больше не пропускает первые десять лотов. Нулевой номер
   старых диагностических запросов принимается как первая страница.
