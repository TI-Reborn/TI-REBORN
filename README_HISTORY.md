## Проверка и использование

Из `C:\TIO-emulator`:

```powershell
python -m unittest discover -s tests -v
python tools/verify_auth_native.py
python -m tio encode-auth-result --status 0 --unknown-u32-01 0x12345678
python -m tio decode-auth-result '02 00 78 56 34 12'
```

Codec и unit-тесты требуют только Python 3.10+. Native probe дополнительно
требует `pefile`, `unicorn` и точный установленный `silver.dll`; SHA проверяется
перед исполнением. Анализ бинарников: `pefile`, `capstone`; runtime probes: `frida`.
`python -m pip install -e '.[research]'` устанавливает дополнительные инструменты.

Команды CLI работают с **application bytes, без транспортного заголовка**.
Golden bytes синтетические: поле `0x12345678` выбрано для проверки endian,
не взято из реального соединения.
