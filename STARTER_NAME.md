# Имя первого бойца

Первый человеческий боец (pet_id=1) с диагностическим именем ProbeNew
получает имя персонажа своего аккаунта из characters.name, slot=1.
Исправление выполняется в транзакции OwnedPetStore.ensure при входе:
для новых аккаунтов сразу после создания, для уже существующих — при следующем входе.
Остальные поля пакета, инвентарь и имена нанятых бойцов не меняются.
Если первый боец уже имеет другое имя, оно сохраняется.

Обновление для VPS: data/tio-starter-name.tar.gz и deploy/install_starter_name.sh.
Скрипт сохраняет код и базу, обновляет только tio/owned_pets.py и перезапускает
игровую службу. Лаунчер и клиентские файлы обновлять не нужно.
Применение на хостинге требует запуска скрипта пользователем через SSH.

Проверки tests/test_owned_pets.py: новый аккаунт, исправление сохранённого
бойца, изоляция аккаунтов, сохранение инвентаря/полей, повторный вход,
сохранение имени другого бойца и пользовательского имени первого.
