# Аудит запросов — обновление 2026-09-28

Исторические счётчики ниже относятся к 2026-09-19. Команда 76 уже подключена
к покупке золота; BA01 на хостинге обслуживается реальным браузером комнат
server/team_arena.py (TEAM_LOBBIES.md). Их нельзя считать недоделанными
по старому fallback локального обработчика. Эффекты и умения: WEAPON_EFFECTS.md.

Проверены текущий `tools/loopback_exchange.py`, подключённые сервисы и 98
сохранённых файлов логов с 51 семейством запросов после авторизации.
Первоначально 11 семейств из этих записей не получали ответа. После
восстановления шаблонов C5 01 и достижений B5 01 оба отвечают списками;
последующие исправления отмечены ниже. Достижения описаны в [ACHIEVEMENTS.md](ACHIEVEMENTS.md).
Это не полный перечень всех команд оригинального клиента.
Текущая запущенная игра не перехватывалась, интерфейс заново не обходился.

Счётчики относятся к историческим записям, а не к уникальным игровым сессиям
или последнему запуску. Дубли двух форматов внутри одного файла исключены;
копии одного запуска в разных файлах могут увеличивать число наблюдений.
Исправленные за прошедшие этапы команды сопоставлялись с нынешним кодом,
а не объявлялись неисправными по старому отсутствию ответа.

## Отдельные случаи

- `50 03`: уведомление города/панели, builder `7ceb48`. В обычном состоянии
  ответа нет; после завершения боя `ArenaService.city_roster_refresh` использует
  его для повторной отправки отряда. Не считаем безусловным дефектом запроса.

  кланового членства/прав. `69 03`: пустой почтовый список B775. Личный склад
  не раскрывается через эти виды; переносы в них запрещены.
- `B1 02`: с 29.09.2026 возвращает личные постоянные услуги и оплаченные уровни;
  `B1 04` обрабатывает покупку. Общий аукцион также подключён. Ограничения:
  [SERVICES_AUCTION.md](SERVICES_AUCTION.md).
- `BA 01`: хостинг возвращает фактический список комнат через TeamArena;
  пустой ответ локального fallback не описывает серверный браузер комнат.
- `B4 0C`: получает пустой вспомогательный список `B4 0D 00 00` из SC-магазина;
  бизнес-смысл списка пока не восстановлен. Это ответ-заглушка, не молчание.
- Неподдержанные эффекты оружия, неосуществимые действия и бои со ставками
  могут получать сообщение об отказе. Это тоже не отсутствие ответа.

## Воспроизведение и границы проверки

Команда: `python tools/audit_unanswered_requests.py`.

18 проверок исполняют существующий `observe_game` с оригинальным Python
кодеком транспорта и перехватом всех исходящих фреймов. Для каждого запроса
создаётся отдельная временная SQLite-база, состояние — обычный город без боя.
Последующий EOF завершает цикл; для всех проверяемых пропущенных пакетов
чтение кода также подтверждает отсутствие отложенного обработчика.
Контрольный ping `70` получает `9E`.

Результаты, варианты пакетов и пути к исходным логам сохранены в
`evidence/unanswered_requests_audit.json`. Проверка не отправляет запросы в
живую игру, не изменяет `data/reservation.sqlite3` и не исправляет протокол.

Шаблоны `C5 01` и достижения `B5 01` восстановлены. Следующие кандидаты:
рейтинги; список комнат `BA 01` уже восстановлен. У неизвестных
команд сначала следует восстановить назначение и ожидаемый формат ответа.
