# Синхронизация игровых обновлений — 18 октября 2026

Снимок подготовлен поверх актуального `main` после PR #4. Из действующего
хостинга перенесены **16 изменённых runtime-файлов**, включая новый
`tio/warehouse_resources.py`. Все 375 записей `docs/HOSTED_SOURCE_20261018.json`
сверены с полученными исходниками; контрольные суммы считают UTF-8 с LF.
В этом файле перечислены только исходники и разрешённые каталоги, а не
конфигурация запуска или содержимое сохранений.

## Что обновлено

  по четыре игрока, полный таймер боя; список групп и уведомления об изменениях,
  корректный счётчик незавершённых боёв. Сохранён и явно выбираемый старый
  режим расписания. [Описание](TRAINING_BASE_20261018.md),
  [список групп](TRAINING_GROUPS_20261018.md),
  [клиентское расформирование](TRAINING_DISBAND_20261018.md).
- **Клановые значки**: сервер принимает штатную загрузку и удаление значка,
  проверяет права и изображение; значки обновляются в чате и тренировочных
  группах. Добавлены исходники Windows-конвертера PNG/BMP в
  `assets/clan-icons/native/` и проверяемые клиентские патчи.
  [Загрузка](CLAN_ICONS_20261018.md),
  [отображение](CLAN_CREST_PROJECTIONS_20261018.md).
- **M60 и Minigun**: стрельба по пустой местности, поражение целей в секторе,
  препятствия, расход боеприпасов и ОД; скрытые попадания не раскрывают цель.
  Геометрия сектора явно описана как правило эмулятора.
  [Подробности](../AREA_FIRE.md).
- **Склад**: количество Upgrade Kit и сумма оставшегося ремонтного ресурса
  личного склада текущего города вместо ошибочного отображения клановых денег.
  Значения обновляются после переноса и ремонта.
  [Назначение всех семи значков](../WAREHOUSE_COUNTERS.md).
- **TrueSkill**: крестик отменяет серверный поиск; открытие окна с пустой
  очередью не сбрасывает выбранных наёмников; запоздавшая отмена не прерывает
  начавшийся бой. Резервные QA-логины подбираются отдельно от обычных игроков.
  [Разбор и проверка](../TRUESKILL_CANCEL.md).
- **Премиум**: добавлены исходники исправления клиентских ценников на кредиты
  и тесты действующей кредитной политики. Серверная оплата кредитами уже была
  в `main` и при этой синхронизации не заменялась.
  [Описание](PREMIUM_CREDITS_20261018.md).

Предыдущие изменения других разработчиков, включая C8/12 и TrueSkill из PR #4,
сохранены. Исходники взяты с работающего сервера, поскольку основной рабочий
каталог содержит также неустановленные исторические варианты модулей.

## Проверки

Серверный preflight `python -m server --check` проходит без открытия listener.
Расширенный `python tools/run_server_checks.py` проверяет прежний переносимый
baseline и новые регрессии на временных локальных БД. Итоговый результат
фиксируется в pull request и GitHub Actions. Локально на Windows Python 3.14
прошли 201 проверка основного расширенного набора и отдельно 18 проверок
режима запуска Training Base по готовности (всего 219). Проверка границ
репозитория: 1839 файлов, находок 0.

Перед отправкой выполняются `python tools/check_handoff.py` и
`git diff --check`. Сохранения, ключи, пароли, адресные конфиги, клиентские
бинарные файлы и приватные отчёты в Git не добавляются.

Отдельные проверки, проведённые ранее при выпуске на хостинг, описаны в
документах изменений: настоящий графический клиент для значков, склада и
отмены TrueSkill; независимые TLS-аккаунты для сетевых сценариев; восемь
аккаунтов для Training Base. Они не подменяются локальными тестами или CI.
Ссылки на `reports/` в исторических документах относятся к приватным
доказательствам владельца: сами отчёты не являются частью этого репозитория.

Исходники патчей DLL и Windows-помощника добавлены для воспроизводимости.
Для их выполнения нужны отдельно доступные оригинальные клиентские файлы и
исследовательские зависимости; portable CI их не запускает. Клиентские DLL,
EXE и игровые ресурсы в репозиторий не включены. Уже опубликованный клиент
**2026.10.18.5** получается через обычный лаунчер.

## Выпуск и данные

Эта операция обновляет GitHub и не развёртывает сервер повторно. В действующем
хостинге указанные изменения уже установлены; серверный код и конфигурация
в ходе синхронизации только читаются. Схема SQLite и пользовательские данные
не изменяются. В CI нет доступа к хостингу и production-секретов.

При необходимости откатить только эту синхронизацию следует отменить её
коммит в Git. Откат работающего сервера — отдельная операция с проверкой
совместимости и резервных копий; его нельзя выполнять восстановлением
пользовательских данных из исходного снимка.
