# Рука над наземным рюкзаком — 2026-10-29

При масштабе интерфейса 125–200% штатный обработчик `silver.dll95D428`
сравнивал физическую полосу клетки с логической координатой мыши Silver.
Рюкзак рисовался, содержимое открывалось через инвентарь → «Выбросить»,
но курсор руки и открытие щелчком не срабатывали.

`launcher/NativeGroundLoot.cs` меняет только два чтения указателя Y мыши
в этой проверке (`95D54E`, `95D55C`) на физический указатель `ti.exe76E440`.
Применяется до ввода пользователя после существующей проверки совместимого
образа Silver. Каждая инструкция проверяется через `GuardedPatch` с учётом
перемещения DLL. Файлы игрового клиента на диске не меняются. Выбор бойца,
клетка, видимость, наличие вещей, AP, запрос открытия и серверная авторизация
остаются штатными. Один обработчик используется всеми режимами боя.

## Проверки

- До исправления `tools/verify_ground_hover_native.py --unpatched` падает
  при масштабе 125%: ожидается рука, получено отсутствие курсора.
- После исправления: 48 PASS на масштабах 100/125/150/200%, двух базах DLL,
  с пустой клеткой, нулём AP, другой клеткой бойца, без выбранного бойца и
  при перекрытом интерфейсе. Выполняется исходный x86 обработчик наведения
  и клика, включая настоящие проверку списка вещей, расстояние и AP.
  Байты исправления получены от собранного C# лаунчера через
  `--ground-hover-proof`, а не только от Python-копии изменения.
- Сборка .NET Release, TLS endpoint probe, self-update self-test — PASS.
- `python tools/check_handoff.py`, `python -m server --check` — PASS;
  `python tools/run_server_checks.py` — 779 PASS.
- В живом клиенте пользователя до исправления 1802 вызова остановились на
  проверке полосы: клетка (20,23), камера Y=96, физическая мышь Y=795,
  логическая Y=530. Физическая полоса 784..800 соответствует наведению.
  После точечного изменения зарегистрированы 66 кадров штатной руки и
  вызов штатного открытия `95E114` для (20,23). Пользователь подтвердил:
  «Рука появилась, рюкзак открывается». Бой не прерывался.

Другие режимы боя вручную этим изменением не проверялись. Клавиша S
не входит в исправление наведения.
