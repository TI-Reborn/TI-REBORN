# Синхронизация установленного Python-кода — 18.10.2026

После выпуска PR #1 исходники действующего сервера сверены с `main`.
В репозиторий перенесены отсутствовавшие установленные исправления: сохранение
здоровья после боя с временным увеличением максимума HP, измерения производительности,
повторное использование проекций в пределах запроса/тика и устранение лишних
SQLite-записей. Также синхронизированы установленные подключения завершённых
сервисов склада, магазина и боёв; зависимости не заменены упрощёнными заглушками.

Обработчик C8/12 из PR #1 сохранён вместе с этими изменениями. Во время выпуска
обратный патч вернул все пять изменённых runtime-файлов к их исходным версиям
на сервере байт в байт. Другой production-код и конфигурация не изменялись.

`HOSTED_SOURCE_20261018.json` содержит хэши 374 файлов Python и runtime-каталогов после
нормализации переводов строк в LF. В репозитории остаются дополнительные
исследовательские утилиты и тесты. Это не полный образ конфигурации VPS.
`SOURCE_MANIFEST.json` сохраняет своё историческое значение исходной передачи.
Базы, пользовательские записи, ключи, адресные конфиги и журналы не публиковались.

Проверка установленного сервера: preflight, два аккаунта через публичный TLS,
один общий бой, запрос C8/12 до/после загрузки и при reconnect, изоляция чужого
списка. QA-аккаунты были исключены из рейтингов и удалены. После очистки все
169 таблиц совпали с резервной копией непосредственно перед выпуском.
Проверка настоящими игровыми окнами отдельно не выполнялась.

Базовый CI дополнен тестами панели умений из PR #1, сохранения здоровья,
изоляции аккаунтов и оптимизаций.
Проверки city-services отделены в economy fixture, чтобы измерения экономического
тика не требовали несвязанных HTTP/router-настроек. Ожидания игрового поведения
не ослаблялись. Исходники хостинга для прохождения тестов не менялись.
