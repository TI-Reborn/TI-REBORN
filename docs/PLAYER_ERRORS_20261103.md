# Магазины, ложное сообщение об уровне и котировки — 03.11.2026

Клиентское обновление **2026.11.03.1** опубликовано и проверено по HTTPS.
Оно меняет 19 байт `silver.dll`; остальные 6979 записей манифеста, TI,
лаунчер, конфигурации игрока и игровые данные сохраняются.

## Причины и изменения

* Нативный построитель каталога `991940` отбрасывал запрос 73 при общем
  флаге ожидания, оставляя окно в загрузке. Теперь чтение каталога отправляется
  по тому же упорядоченному игровому соединению. Защиты построителей покупки
  и серверные проверки денег, владения и состояния не менялись. Путь магазина
  Premium также использует обычный каталог при подготовке окна.
* Сервер применял F0/117 для открытия города. Его штатная ветвь дополнительно
  форматирует и показывает s117 — предупреждение про второй уровень. В клиенте
  эта используемая эмулятором команда открывает город без форматирования и
  доставки предупреждения. Серверные ограничения переходов не менялись.
* C1/04 — изменение общей конфигурации векселей из административного окна.
  Поддерживаемые покупки и котировки используют другие подкоманды. Запрос
  изменения конфигурации получает явный отказ «Настройки векселей задаются
  сервером»; административный редактор банка не реализуется этим исправлением.
* Таймеры разных сессий повторно строили общие списки комнат под общей
  блокировкой. Серверный патч ограничивает только фоновую публикацию списков
  четырьмя проходами в секунду. Боевые таймеры и явные запросы списков работают
  как прежде; допуск к комнате каждый раз проверяется заново.

## Проверки

* Три теста исполняют настоящие x86 ветви: запрос каталога при waiting=1,
  тихое открытие города с сохранением рендера, прежний порядок обычного и
  Premium запросов. До исправления воспроизведены потеря запроса и s117.
* 66 целевых серверных тестов прошли локально и в изолированной копии
  фактического сервера на VPS (на VPS двумя наборами 58 + 8). Временные SQLite, несколько аккаунтов,
  смена пула, удаление комнаты, heartbeat и восстановление боя после падения.
  Старая socket-фикстура heartbeat дополнена существующим settimeout.
* Два временных исключённых из рейтингов аккаунта получили 20 ответов обычного
  и Premium магазинов по публичному TLS. Исходный C1/04 воспроизвёл сообщение
  `Unsupported securities request`. Это протокольная проверка, не GUI.
* Один отдельный настоящий клиент запущен опубликованным лаунчером 0.1.46.
  Выполнены обычная нативная авторизация и выбор персонажа; вручную через
  Windows UI открыты оба магазина. Обе пары request/reply завершились с
  waiting=0/loading=0. В городе ложное предупреждение не появлялось.
  Покупки и бой этим графическим прогоном не проверялись.
* Принятый общий набор: по 498 проверок исходной версии и кандидата. В
  кандидате остаются 82 старых сбоя, новых относительно baseline нет.
  `tools/check_handoff.py` отсутствует и в локальном checkout, и на хостинге.
  Полный CI не объявляется зелёным.
