# Досрочный результат шахты только по команде меню

Уточнение владельца 17.11.2026: наличие бура и количество кристаллов
проверяются для досрочного результата только после «Покинуть битву».
Отдельно подтверждено: при живом рейдере после пяти ходов команда меню
доступна у входа/выхода, а движение к нему само по себе бой не завершает.

## Итоговые правила

- Движение внутри стартовой зоны, уход из неё, возвращение к выходу,
  получение бура и завершение хода не запускают извлечение кристаллов
  и не формируют досрочный результат — даже с наполненным буром.
- Без бура у живого наёмника запрос «Покинуть битву» отклоняется.
- С пустым буром или недостатком кристаллов явный выход даёт поражение.
- Для победы требуется минимум 100 кристаллов в шахтах 4–6 и 7–10;
  минимум 200 в шахтах 11–15 и 16–20.
- После присоединения рейдера первые пять полных ходов выход закрыт.
- После блокировки, пока есть живой противник другой стороны, весь
  живой отряд должен находиться в своей зоне выхода для команды меню.
  Без такого противника команда разрешена из любой точки при наличии бура.

`server/mine_arena.py::mine_after_action` теперь только обновляет доступность
кнопки; больше не вызывает `MiningBattle.exit` или расчёт результата.
Из `server/team_arena.py` удалён триггер автоматического выхода при движении.
`tio/mining.py::can_quit` разрешает явный выход у входа после окончания
блокировки даже при живом противнике. Существующие интерфейсы сохранены.

## Проверки

Два новых сценария сначала воспроизвели прежнее автоматическое завершение:
возвращение к выходу без команды и движение с наполненным буром. Отдельный
тест сначала подтвердил запрет кнопки у выхода при живом противнике после
пятого хода. После изменения все 58 тематических тестов прошли локально.

Обновлены сценарии общей шахты: они теперь отправляют явный пакет меню,
проверяют отказ без бура и поражение с пустым буром для каждой роли.
Проверены пороги 99/100 и 199/200, блокировка, живой противник, общие
выплаты, повторные запросы, восстановление checkpoint и откат при ошибке БД.

Публикация: `tools/deploy_mine_menu_exit_20261117.py`, только три runtime-файла.
Проверка публичного TLS: `tools/verify_mine_spawn_exit_hosted_20261117.py`.
Логи и результаты: `reports/mine-menu-exit-20261117/`.

## Публикация и приёмка

Прошли 730 обязательных серверных тестов и 58 тематических тестов на хостинге.
После проверки отсутствия боёв и незавершённых расчётов выполнена публикация.
Backup: `/root/tio-before-game-operations-mine-menu-exit-20261117-20261117`.
Проверены хеши трёх runtime-файлов, сохранность 175 таблиц при замене кода
и защищённых данных после перезапуска. 93 аккаунта, SQLite integrity — OK.

На опубликованном сервере два временных исключённых из рейтингов аккаунта
прошли публичный TLS-сценарий в шахтах 11–15 и 16–20: пустой бур доступен
в инвентаре, сервер включает кнопку выхода; первый шаг и возвращение к
выходу оставляют тот же бой активным, HP не меняются; только явный пакет
«Покинуть битву» возвращает поражение. Оба аккаунта затем штатно вернулись
в город и удалены после подтверждённого отсоединения игровых сессий.
Графические клиенты не использовались; пороги победы и рейдер проверены
автоматическими сценариями общей шахты с несколькими аккаунтами.
