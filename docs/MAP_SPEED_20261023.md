# Скорость глобальной карты: 6 → 12

По запросу пользователя скорость «звёздочки» увеличена ещё вдвое:
`tio.locations.MAP_SPEED = 12` единиц карты в секунду. Сервер использует
это значение для времени пути, групповых маршрутов и поля скорости
первоначального пакета 1A, по которому клиент выполняет интерполяцию.
Обновление клиентских файлов не требуется; новый вход получает скорость 12.

Изменён только `tio/locations.py`. Перед переключением проверяются отсутствие
активных боёв и отсутствие ещё идущих одиночных/групповых маршрутов. Повторная
проверка выполняется после остановки сервиса, чтобы старое время прибытия
не сочеталось с новой скоростью клиента. Завершённые offline-маршруты и все
сохранения сохраняются без изменения.

Резервная копия настоящей БД, прежних кода/config/systemd:
`/root/tio-before-game-operations-map-speed-20261023`.
При переключении все 172 таблицы сохранены; локальные данные игроков не
загружались. Сервис перезапущен штатно, незапланированных рестартов нет.

На копии текущего hosted runtime прошли 36 автоматических тестов: одиночный
путь и восстановление, групповой путь двух/четырёх участников, встречи в пути,
bootstrap и TCP-перемещения. В тестах встреч фиксированные расстояния теперь
не зависят от старой скорости. Клиентские XML для отдельного теста ресурсов
передавались только в изолированный проверочный каталог, без публикации.

На точном публичном Silver выполнены оригинальные x86 функции движения,
остановки и интерполяции в Unicorn со скоростью 12; графический клиент
в этой проверке не запускался. На публичном TLS два одновременно вошедших
протокольных клиента получили 1A со скоростью 12, отправили настоящие 1B и
прошли по независимому маршруту длиной 36. Серверные записи давали ровно
3 секунды для обоих маршрутов; оба клиента получили 1D и остановку 1E в цели.
Это проверка игрового протокола, а не визуальная проверка GUI.

Тестовые аккаунты исключены из рейтингов зарезервированными логинами и
удалены после проверки. Чужие строки сохранены, 31 аккаунт и 3 прежних клана,
integrity `ok`, все службы active. Ранее опубликованный общий склад сохранён.
