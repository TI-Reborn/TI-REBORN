# Синхронизация хостинга — 26 октября 2026

На хостинг установлены изменения main из PR #34–#37 и исправления PR #38.
После установки повторно прочитаны 410 серверных исходников и публичных
каталогов: все совпадают с этой веткой после нормализации UTF-8/LF.
Контрольные суммы приведены в `HOSTED_SOURCE_20261026.json`.

Исправления классификатора тестов:

- Отсутствующий файл внутри репозитория на Windows остаётся реальной ошибкой.
- Известное падение совпадает только по конкретному тесту, виду падения,
  классу исключения и полному сообщению. Исключения целых модулей удалены.
- JSON-отчёты сохраняются в UTF-8, включая сообщения на русском языке.

Из действующего серверного каталога перенесены 101 ссылка на новые иконки;
манифест иконок пересоздан из этого каталога. Характеристики предметов совпадают.
Клиентская публикация и её манифест при этой установке не менялись.

## Проверки

- Windows: `tools/check_handoff.py`, `python -m server --check` прошли.
  Обязательная выборка: 688 тестов, все прошли. Последнее исправление UTF-8
  дополнительно проверено всеми 9 тестами классификатора.
- Linux: отдельный каталог кандидата на VPS, запуск от пользователя `tio`.
  Обязательная выборка: 688 тестов, успешно, 2 пропуска без установленного
  клиента Windows. Все 9 тестов окончательного классификатора прошли отдельно.
- Восстановление боя: 16 тестов прошли на Windows и Linux, включая реальное
  аварийное завершение процесса и восстановление двух аккаунтов через TCP.
- Проверка списка известных ошибок: 283 теста, 77 точных совпадений `known`,
  8 прежних ошибок `real`, код выхода 1. Все восемь уже перечислены в
  `FULL_TEST_SUITE.md`. Полный legacy-набор повторно не запускался.
- На рабочем сервере два временных аккаунта прошли вход через публичный TLS,
  независимые команды, переносы предметов, проверку стаков и уникальности ID,
  быстрый ремонт со склада и повторный вход с сохранёнными остатками.
  Ремонт списал 291 ресурс, сохранил набор в рюкзаке и данные второго аккаунта.
- Это протокольная проверка: графические игровые клиенты не запускались.

## Сохранность и рабочее состояние

Перед заменой сделаны резервные копии кода, конфигурации и остановленной базы.
Сравнение всех 175 существующих таблиц до и после перезапуска подтвердило
неизменность строк. Сохранены 37 аккаунтов, 46 персонажей и 3 клана.
Локальная база на хостинг не загружалась; база из копии не восстанавливалась.

Сервис `tio-server` активен, PID после установки 700969, автоматических
перезапусков нет. Четыре вспомогательных сервиса, конфигурация и манифест
клиента сохранились. Публичные TLS-порты доступны, внутренние игровые порты
доступны только через loopback. Целостность SQLite — `ok`.
Поддержка WAL установлена, текущий режим `delete` и настройки не менялись.

QA использовал только случайные имена из зарезервированного пространства,
исключённые из рейтингов до начала проверки. Все созданные фикстуры удалены;
схема и посторонние строки сохранены. Итоговые количества снова 37/46/3.
