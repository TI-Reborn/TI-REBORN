# Обязательный лаунчер — 20.10.2026

Опубликованы лаунчер **0.1.24** и клиент **2026.10.20.3**. Старые установленные
копии должны один раз открыть лаунчер, чтобы получить новые файлы. Уже
сохранённый у игрока старый EXE физически изменить удалённо нельзя, но его
прежний путь подключения больше не допускает вход на хостинг.

## Поведение

- Прямой запуск нового ti.exe показывает «Запускайте игру через TIO Launcher.
  Лаунчер должен проверить и установить обновления перед входом» и завершает
  процесс после ОК, до меню игры.
- Каждая команда «Играть» проверяет HTTPS-манифест лаунчера заново. Версия
  должна точно совпадать с опубликованной. Затем проверяется/устанавливается
  текущий выпуск клиента, включая SHA256 исполняемых файлов. Открытый ранее
  лаунчер не может повторно использовать свой устаревший флаг `verified`.
- Локальный TLS helper передаёт на обоих внешних каналах 46 байт: `TIOT`,
  версия 2, язык, порт, SHA256 проверенного тела манифеста клиента и три u16
  компонента версии лаунчера. Сервер читает ровно этот заголовок с ограниченным
  сроком и сравнивает с текущими манифестами публикации. Старый заголовок,
  старый клиент или старый лаунчер не получают даже native auth challenge.
- Порты 28512/28513 привязаны к loopback. Внешние игроки используют только
  проверяемые TLS 29512/29513. Локальные интерфейсы сервера сохранены.
- После подтверждения запуска native игры окно лаунчера закрывается.
  Существующий фоновый helper остаётся для TLS и владения процессом игры;
  закрытие окна лаунчера не закрывает игру. При ошибке окно остаётся открытым.
- Ресурсы значка самого ti.exe заменены на те же девять изображений ICO, что
  встроены в лаунчер. Первоначальные секции кода сохранены побайтово.
- `.previous-*` больше не остаётся после успешного самообновления. Во время
  атомарной замены необходима временная локальная копия для отката при ошибке;
  после запуска проверенной замены она удаляется. При запуске удаляются старые
  соседние `TIO-Launcher-VERSION.exe.previous-HEX` / `TIO Launcher.exe.previous-HEX`
  с настоящим ProductName `TIO Launcher`; обычные пользовательские файлы не
  затрагиваются. `.tio-update/backup` очищается после завершения/отката транзакции,
  когда журнал восстановления уже отсутствует. История выпусков и полноценные
  резервные копии остаются на сервере, данные игроков туда не отправляются.

Проверка выпуска относится к официальному лаунчеру и обычному запуску клиента.
Поля версии протокола не являются удалённой аттестацией против намеренно
переписанного EXE или самодельного протокольного клиента. Секреты, пароли и
пользовательские сведения не добавлены в заголовок допуска.

## Проверки

33 автоматических серверных теста на свежем изолированном runtime VPS:
обязательные обе TLS-ветви, запрет v1 и устаревших выпусков, немедленная смена
правил при публикации следующего манифеста, ограничение чтения, два аккаунта,
прежняя авторизация и TLS. Локальные тесты будущего login/economy boundary
не входят в поставку: соответствующие методы отсутствовали в исходном runtime
VPS; игровые правила и инициализация экономики этой задачей не изменялись.

Проверки лаунчера: updater, launcher-update, archive, cache, language, game-path,
install-location, TLS и новая launch-required группа. Проверена очистка
`.previous-*` на копии настоящего self-contained EXE, сохранность постороннего
файла и удаление временных резервных копий после ремонта файлов. Тест значков
окон прошёл в обычном видимом режиме; скрытый процесс не показывал тестовое
окно, поэтому его первый запуск не является успешной проверкой UI.

Unicorn исполнил native gate в прямом/разрешённом режимах при двух адресах базы;
проверены 9 PNG/DIB ресурсов ICO. Отдельный тестовый C# harness, не входящий
в публикацию, запустил настоящий скрытый owned native клиент: gate released,
ORANGE loaded, TLS route verified, затем завершил только свой процесс.

Публичный хостинг: два исключённых из рейтингов QA-аккаунта входят одновременно
с актуальным заголовком, получают свои ресурсы и повторно подключаются.
Проверены отказы старого login/session заголовка и старых client/launcher
версий, недоступность прежних открытых TCP портов. QA-аккаунты удалены; проверка
очистки сохранила все посторонние строки и схему.

В настоящем GUI текущего опубликованного EXE кнопка Play закрыла процесс окна
лаунчера; native игра продолжила работать с фоновым helper. Аккаунт в этом
графическом прогоне не авторизовывался. Отдельно настоящий прямой ti.exe показал
сообщение блокировки и завершился после нажатия OK. Вход двух аккаунтов выше
проверялся отдельными протокольными клиентами.

## Поставка

Сервер меняет только `server/config.py`, `server/tls.py`, две ветви
`server/multi.py` поверх точного снимка хостинга; конфигурация получает
`tls.launch_manifests="/var/www/tio-client"`. Подключённых игроков и сохранённых
боёв перед перезапуском не было. Все 172 таблицы сохранены; локальная база
игроков не загружалась.

Резервные копии:

- `/root/tio-before-launcher-q4svgxms`: предыдущий лаунчер, код, конфигурация,
  SQLite и проверенный полный PostgreSQL dump сайта.
- `/root/tio-before-required-launcher-client-cht36mv4`: прежний ti.exe,
  манифест, код/config и SQLite перед публикацией клиента.
- `/root/tio-before-game-operations-launcher-required-20261020`: код/config,
  две проверенные SQLite копии перед заменой серверных файлов.

Артефакты: `reports/launcher-required-20261020/`. Воспроизведение:
`tools/build_required_launcher_client_20261020.py`,
`tools/deploy_launcher_required_20261020.py`,
`tools/publish_required_launcher_client_20261020.py`,
`tools/verify_required_launcher_native_20261020.py`,
`tools/verify_launcher_required_hosted_20261020.py`.
