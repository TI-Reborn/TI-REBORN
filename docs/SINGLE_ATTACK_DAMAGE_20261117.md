# Один расчёт урона на атаку — 17.11.2026

Уточнение владельца: очередь АК-47 — анимация и расход 5 патронов;
сервер должен рассчитывать попадание и урон один раз за клик по противнику.

## Причина малого урона

Предыдущая реализация `tio/combat_rolls.py` делила урон очереди между пулями
и независимо проверяла попадание каждой. В общей шахте 11–15 воспроизведено:
АК-47 +20, уровень наёмника 15, «Автоматическое» 145, дистанция 1,
броня мутанта 270 — одна попавшая пуля из пяти снимала 8 HP,
вся попавшая очередь — 41–53 HP. Это воспроизведение возможного сценария,
а не восстановление случайных бросков конкретного выстрела пользователя.

Навык не терялся: при тех же условиях навык 35 давал 20–25 HP за всю
очередь. В прочитанном активном checkpoint шахты навык 145 также сохранялся.
До последних изменений броня шахты 11–15 уже составляла 270: это проверено
по резервной копии перед обновлением gameplay-feedback. Хеши старых
`combat.py`, `combat_rolls.py`, `weapon_proficiency.py` совпали с этой копией.

## Исправление

Общий обработчик `burst` теперь делает один бросок попадания, один выбор
урона и один бросок критического удара для атаки по цели. При промахе
выбор урона и критического удара не выполняется. Критический удар удваивает
весь урон до применения брони. Существующий API сохранён.

Количество патронов влияет на расход боеприпасов, а не на долю урона.
АК-47 по-прежнему тратит 5 патронов и 5 ОД при попадании и промахе.
Общий обработчик применяется ко всем видам оружия с очередью. У площадных
атак сохраняется отдельный расчёт для каждой поражаемой цели.
Клиентские файлы и анимации не менялись.

С текущими правилами для АК-47 +20, уровня 15, навыка 145 и брони 270:

| Дистанция | Обычное попадание, HP |
| --- | --- |
| 1 | 41–53 |
| 4 | 37–48 |
| 9 | 31–40 |

Промах снимает 0 HP. Минимальный критический удар на дистанции 1 снимает
83 HP: `floor((155 * 2) * 100 / 370)`. Лимит навыка на уровнях 11–15 равен
125/130/135/140/145; глобальное значение 200 ограничивается уровнем наёмника.

## Возврат расчёта по каждой пуле, 18.11.2026

На хостинге восстановлен прежний `tio/combat_rolls.py`. Сервер берёт число
патронов из каталога оружия и для каждой пули отдельно проверяет попадание.
Каждая попавшая пуля получает свой бросок урона и крита. Урон пуль
суммируется по цели, а полным промахом считается атака без попаданий.
Например, AWP выполняет один расчёт, АК-47 и Steyr Aug — пять, HK G3SG/1 — три.

[Руководство, с. 57 и 60](../reports/chat-presence/TIO_manual.pdf) описывает
независимую точность пуль и трёхпатронную очередь G3SG/1. REA с Rizin
подтвердил в оригинальной `silver.dll` чтение количества патронов
(`0xa72279`), дистанционную точность (`0xa7ad00`), одну команду атаки
(`0x95dfe8`) и ветку отображения промаха (`0x960709`).
Точное распределение урона исторического сервера остаётся неизвестным.

Перед заменой файла сохранены база и предыдущие код и конфигурация.
Сверены все 175 таблиц и 95 аккаунтов. Целевые 92 теста прошли локально
и в изолированной копии на VPS, с одним ожидаемым сбоем Перфоратора.
Установленная служба активна, оба игровых TLS-порта отвечают.
Отчёты [выкладки](../reports/restore-weapon-hits-20261117/server-deploy.json)
и [проверки установленного кода](../reports/restore-weapon-hits-20261117/installed.json).
