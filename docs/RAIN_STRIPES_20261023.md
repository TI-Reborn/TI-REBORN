# Military Outpost: прямоугольники вместо дождя

Опубликован лаунчер **0.1.31**. Исправление начинает действовать после закрытия
игры, обновления лаунчера и нового запуска через него.

Причина — ANSI-константа `gfx\\rain.tga` в расширении погоды Silver при вызове
Unicode API движка. Файл существует и содержит корректную прозрачность, но
движок получал искажённое имя и подставлял полностью непрозрачную текстуру
`none` размером 32×32. Отрисовка её как 8×32 с полупрозрачным цветом создавала
двигающиеся вертикальные полосы.

`NativeRainWeather` исправляет только 26 байтов строковой константы по RVA
`0x87f100` в памяти собственного запускаемого клиента. Длина, постоянный
счётчик ссылок и соседние данные сохраняются. Полный хеш известного Silver и
исходные байты проверяются перед записью. Адаптер включён в существующую
цепочку `NativeDoorGrid.BindRecon`. Неизвестные DLL не изменяются.

Релиз собран из сохранённого исходного кода опубликованного 0.1.30 в
`work/password-client-20261023/source`, с четырьмя изменёнными/новыми файлами:
`NativeRainWeather.cs`, `NativeDoorGrid.cs`, `Program.cs`, `TioLauncher.csproj`.
Это исключает попадание других незавершённых изменений основного checkout.
Копия исходников выпуска: `work/rain-stripes-20261023/source`.

Проверки:

- Родной загрузчик и Direct3D9 настоящего отдельного клиента воспроизвели
  заглушку: 32×32, alpha=255 для каждого пикселя. После исправления: 64×64,
  alpha=0…56, 3755 полностью прозрачных пикселей. Проверены реальные данные
  GPU через LockRect, а не только декодирование Pillow/D3DX вне игры.
- Родной рендерер показал прямоугольники у исходного варианта и прозрачные
  капли у исправленного. Проверка выполнена в меню без принятия соглашения
  и без входа в аккаунт; это не проверка завершённого сетевого боя.
- Проверен исправленный путь в памяти нового клиента, запущенного цепочкой
  лаунчера; сертификаты обоих hosted TLS endpoints проверены.
- После публикации повторён свежий запуск 0.1.31: собственная функция LOAD
  расширения дождя загрузила именно прозрачную текстуру 64×64. В этом запуске
  QA-сборка отличается от публичных исходников только разрешением отдельного
  параллельного тестового клиента; код исправления идентичен.
- Пройдены проверки адаптера, паролей длиной 64, TLS и самообновления;
  updater проверен в отдельной QA-сборке с отключённым глобальным запретом
  параллельного клиента. Публичная сборка сохраняет этот запрет.
- Все пять серверных тестов погоды проходят. Погодные пакеты, общая логика
  боя и immutable `silver.dll` не изменены.

Публикация использовала свежую резервную копию
`/root/tio-before-launcher-at1hj7v3`: согласованную SQLite, восстановленный в
изолированную БД PostgreSQL dump, предыдущий лаунчер, код и конфигурацию.
Игровые сервисы не перезапускались; игровые аккаунты и сохранения не
редактировались. Тестовые аккаунты не создавались.
