# Повторный пропуск хода на стрельбище

Подтверждённая причина: стрельбище использует отдельный `ArenaService`.
После `EndTurn` следующий ход начинается сразу. Повторный пакет старого
клиента не содержит номера хода и завершал уже новый ход, расходуя лимит
20 ходов и отправляя клиенту обнуление AP и `TurnFinished`.

`tio/arena_service.py` хранит ограниченное окно повторов отдельно для каждой
комнаты стрельбища. Завершение вручную и по таймеру открывает окно; начало
следующего хода продлевает его на одну секунду. Повторы внутри окна не
меняют состояние и не отправляют завершение хода или обнуление AP.
Повторы не продлевают окно. Следующий намеренный пропуск после окна работает.
Принадлежность бойца и формат пакета по-прежнему проверяются.

Длительность и чистая проверка окна общие с существующей защитой шахты:
`tio/turn_repeats.py`, `server/team_arena.py`. Поведение общего боя сохранено.
`tio/battle_snapshot.py` переносит срок окна на новые монотонные часы при
восстановлении и читает прежние checkpoints без нового поля. Выход удаляет
состояние окна. Формат сетевого протокола, игровые награды и схема БД не меняются.

Ограничение старого протокола: без идентификатора хода нельзя точно отличить
поздний повтор от нового нажатия. В первую секунду нового хода стрельбища
после завершённого хода пропуск игнорируется; остальные действия доступны.
Первый ход сеанса этим окном не ограничен.

Регрессии: `tests/test_shooting_range_turn_repeats.py`, включён в
`tools/run_server_checks.py`. Тесты сначала воспроизвели ошибку на исходном
коде, затем прошли с исправлением. Покрыты тройные повторы до/после начала
следующего хода, таймер, медленный переход, настоящий следующий пропуск,
непродление окна повтором, чужой боец, восстановление, старый checkpoint,
очистка и полный лимит 20 ходов. Сетевой тест проводит два независимых
аккаунта через все 20 ходов с тройными пакетами между ними.

Локальный baseline: 559 тестов, OK. `python -m server --check` и
`python tools/check_handoff.py` прошли. Исторический дополнительный
`test_battle_turn.test_original_packets` требует отсутствующий в экспорте
`evidence/end_turn_native.json`; это ограничение расширенного suite.
Автоматические и сетевые проверки не заменяют проверку графическим клиентом.

Для установки добавлен scope `shooting-range-turns` в существующий deployer:
ровно четыре runtime-файла, staging, резервные копии БД/кода/config, проверка
исходного runtime и отказ при сохранённых боях/расчётах. Локальные данные
игроков не загружаются; БД не восстанавливается и не мигрируется.
