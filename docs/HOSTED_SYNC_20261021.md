# Синхронизация исходников хостинга — 21 октября 2026

Репозиторий обновлён поверх `main` от 18 октября из фактических файлов
`/opt/tio-emulator` действующего сервера. Перенесены 37 изменённых файлов
runtime и каталогов. Все 390 файлов, перечисленных в
[HOSTED_SOURCE_20261021.json](HOSTED_SOURCE_20261021.json), совпадают с
полученным снимком после нормализации UTF-8/LF. Дополнительные исходники,
исследовательские инструменты, тесты и документация репозитория сохранены.
Исторические манифесты сохраняют свои прежние даты и значение.

## Проверки

`python -m server --check` проверяет ресурсы без открытия listener.
`python tools/run_server_checks.py` сохраняет предыдущий baseline и добавляет
регрессии перечисленных изменений на временных локальных базах и loopback.
Ожидания тестов TrueSkill обновлены под действующие составы 4×4 с ботами;
полностью человеческий сценарий 4 против 2+2 по-прежнему проверяет все
рейтинговые квитанции. Проверка SVD учитывает установленное имя значка.
Тесты ремонта явно закрывают SQLite-соединения перед удалением временной БД.

Для TLS-теста генерируются одноразовые сертификат и ключ в системном
временном каталоге: OpenSSL на Linux или PowerShell 7 на Windows.
Сертификаты, ключи и production-секреты в Git не добавляются.
Старый `tools/run_server_checks.py` с хостинга намеренно не перенесён:
в нём отсутствуют ранее добавленные в GitHub регрессионные модули.

Перед публикацией выполняются `python tools/check_handoff.py` и
`git diff --cached --check`; итоговый результат CI фиксируется в pull request.
Локально на Windows/Python 3.14.7 прошли все 344 теста расширенного baseline,
preflight и проверка 1868 файлов репозитория: 0 находок.
Эта синхронизация не является полным прогоном исторического research-suite.
Ограничения прежних проверок описаны в [VALIDATION.md](VALIDATION.md).

## Границы синхронизации

С хостинга только прочитаны исходники и разрешённые общие каталоги.
Служба не останавливалась и не обновлялась; БД, сохранения и конфигурация
запуска не копировались. Клиентские EXE/DLL, ресурсы, сайт и исходники
лаунчера относятся к отдельным поставкам и в серверный репозиторий не входят.

Результаты прежних protocol/native/GUI-проверок относятся к соответствующим
выпускам и описаны в их документах. Новая игровая проверка настоящими
клиентами или production-аккаунтами при синхронизации GitHub не выполнялась.
Откат GitHub — revert коммита синхронизации; он не откатывает работающий сервер.
