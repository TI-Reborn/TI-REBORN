# Глобальная карта по дорогам — клиент 2026.10.29.1, лаунчер 0.1.40

Новая глобальная карта по согласованному макету. Локации нарисованы прямо на карте
и перенесены на её дороги. Отряд ездит по дорогам, маршрут виден пунктиром.

## Что видит игрок

- Подложка — запечённая карта: 21 локация вписана в местность по силуэтам своих
  построек, у каждой крупная подпись (NY, MZ, MO, RES, MT, DENVER и т. д.).
  Мелкие встроенные подписи этих локаций скрыты; полное название и сведения
  показывает штатная плашка при наведении. Подписи одинаковы для русского и
  английского клиента: имена локаций в игре английские.
- Карта всегда слегка притемнена. При наведении локация светится оранжевым
  контуром с тёмной каймой, остальная карта притемняется сильнее. Без наведения
  пунктиром обведены текущая локация и цель поездки. Тюрьма при наведении обведена
  красным: туда попадают только по приговору.
- Плашка с информацией появляется у курсора: в нижней половине карты над ним
  (низ области карты закрыт чатом), у правого края — слева от курсора.
- Отряд — золотая стрелка, повёрнутая по ходу движения (32 направления).
  Едет только по дорогам со скоростью 36 единиц в секунду, маршрут от старта до
  цели показан золотым пунктиром.
- Клик по тюрьме пишет в чат «В Prison попадают только по приговору» вместо
  общего «запрос не выполнен».
- Правый нижний угол (круглый виджет) и полоса под чатом свободны от локаций.

## Сервер

- `config/world_roads.json` — дороги в мировых координатах. Узел `L<id>` — место
  стоянки локации: там отряд стоит в городе, туда приезжает и оттуда уезжает.
  `tio/roads.py` строит кратчайший путь по дорогам; точка вне дорог (остановка
  после собак, метка контракта, старое сохранение) присоединяется прямым отрезком
  к ближайшей точке дороги.
- `tio/locations.py`: поездка хранит свой путь (`map_journeys.path`), позиция
  считается по времени вдоль пути. Пакет 1D уходит один раз на каждый поворот,
  с упреждением 0,2 с; прежних поправок 12 раз в секунду больше нет. `center()`
  теперь место стоянки, `MAP_SPEED = 36`. Групповые поездки
  (`tio/party_travel.py`, `travel_party_journeys.path`) идут так же.
- Пройденное расстояние для встреч с собаками считается по дороге.
- Границы всех локаций перенесены во всех источниках: `tio/cities.py`,
  `tio/locations.py`, `config/world_completion.json`, `config/mining.json`,
  `evidence/zones_diagnostic.xml` (его получает клиент). Метки трёх контрактов
  (`config/pve_contracts.json`) стоят у дорог на свободных местах.
- `tio/world_layout.py` при старте сервера: персонажи в городах ставятся на новые
  места стоянки; поездки, начатые до переноса, завершаются при следующем обновлении
  в перенесённом месте назначения (старые прямоугольники нужны только для этого).

## Протокол (совместим со старыми клиентами)

Оригинальный обработчик 1D читает оба поля Z и выбрасывает их. Сервер использует
их: второе — конечная локация поездки (0 — нет), первое — слова маршрута
(`tio/protocol/map_route.py`). При старте поездки и при переподключении уходит
пачка одинаковых 1D: заголовок с числом штрихов, затем по одному штриху на пакет.
Штрихи нарезаны в пикселях запечённой карты (x 11 бит, y 10 бит, смещение конца
по 5 бит со знаком). Старый клиент получает те же позиции и повороты.

## Клиент

`deploy/client_global_map_roads.py` — байтовый патч опубликованного Silver
2026.10.28.2 (`3f0f31f0…`). Меняется только код и данные, добавленные патчем карты
`client_global_map.py`, и пять вызовов в оригинальном коде:

- `0x88b172` и `0x88b19c` — чтение полей Z пакета 1D (слова маршрута, конечная локация);
- `0x9ec2b5`, `0x9ec2ca`, `0x9ec2df` — плашки города и базы/шахты: позиция от курсора,
  встроенный сдвиг «не закрывать отряд» на время вызова отключён.

Загружаются 75 текстур (`base/pda/global-map-v3`): карта, по два спрайта подсветки на
локацию (наведение и пунктирная обводка) и 32 кадра стрелки. Прямая линия до
следующей точки (старый путь отряда) больше не рисуется. Лаунчер 0.1.40 добавляет хеш
нового Silver (`a975f4d0…`); ни одна точка адаптеров лаунчера не попадает в изменённые места.

## Сборка

- Картинки: `python tools/build_global_map_v3.py --client <установленный клиент> --out <workspace>/assets/global-map-v3`.
  Нужны numpy, opencv-python, scikit-image и Pillow (только для этой офлайн-сборки,
  сервер их не использует). Результат детерминирован; хеши и версии библиотек — в
  `assets/global-map-v3/manifest.json`. Инструмент сверяет раскладку с серверными
  границами и проверяет, что локации и подписи не перекрываются.
- Релиз: `python tools/build_global_map_roads_release.py --workspace <workspace> --silver <опубликованный silver.dll>`.
  База — опубликованный manifest 2026.10.28.2 (`b06e9ff5…`, кладётся в
  `reports/global-map-roads-20261029/manifest-before.json`). Меняется `silver.dll`,
  добавляются 75 PNG; остальные 6905 строк без изменений.

## Развёртывание

1. Остановить сервис. Поездки в пути не мешают: при запуске они завершатся в
   перенесённых местах назначения, а горожане встанут на новые места стоянки.
2. Обновить код и конфигурацию сервера; запустить сервис.
3. Опубликовать клиент 2026.10.29.1 и лаунчер 0.1.40.

До публикации клиента старые клиенты играют с новыми границами по старой картинке.
Поля Z они игнорируют.

## Проверки

- Сервер (стандартная библиотека): `test_roads` (путь, съезд с дороги, связность всех
  локаций), `test_map_route` (нарезка штрихов, кодирование, пачка 1D),
  `test_map_speed` (скорость, один 1D на поворот, упреждение, два аккаунта,
  перенос сохранений), групповые поездки, собаки, контракты, шахтёры, тюрьма.
- Клиент: `test_client_global_map_roads_native` (Unicorn, две базы загрузки) —
  загрузка 75 текстур, затемнение и подсветка, правило «только наведённая»,
  кадр стрелки по направлению, слова маршрута через настоящий обработчик 1D и их
  отрисовка, плашка у курсора и восстановление камеры, скрытие подписей.
- Настоящий клиент: владелец проверил локально (отдельная копия клиента с этим
  Silver и картинками, локальный сервер, тестовый аккаунт): карта, подсветка, плашка
  у курсора, стрелка, пунктир, поездки по дорогам, встречи с собаками, тюрьма.

Не проверено: работа на хостинге и с двумя клиентами одновременно (на одной машине
запускается только одна копия игры), масштаб интерфейса 125–200 %, английский клиент.
