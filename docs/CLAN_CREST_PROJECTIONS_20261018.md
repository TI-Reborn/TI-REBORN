# Значки в чате и Training Base — 18 октября 2026

Исправление установлено на основной сервер. Достаточно переподключиться:
клиент 2026.10.18.3 и лаунчер 0.1.12 повторно обновлять не требуется.

В списке игроков чата теперь передаются сохранённые ID значков клана и
альянса, уже используемые профилем. Изменение или удаление значка вызывает
обновление списка, даже если уровень, город и боевой статус не изменились.
Это действует для глобального и локальных списков штатными пакетами C7/02 и 4F.

Training Base показывает значки создателей в «Боевых группах» и значок клана
каждого участника в «Моей группе». Группа может содержать участников разных
кланов. Используется ID изображения, а не ID клана. Значки берутся из общей БД;
ожидающая группа получает обновление при их смене без выхода и повторного входа.
Оба поля значков в списке остаются присутствующими: для отсутствующего значка
передаётся 0, сохраняя совместимость с обязательными getters оригинального клиента.

Причина: `Presence.sync()` создавал Player с нулевыми полями crest/alliance;
TrainingArena передавал нули в RoomCell и RoomListItem. Прежняя правка списка
групп устранила исключение на отсутствующих полях, но не подставляла изображения.
Изменены только `server/presence.py` и `server/training_arena.py` относительно
фактически прочитанного кода хостинга. Форматы пакетов и клиентские файлы сохранены.

Проверки:

- 79 тестов проходят в изолированной копии актуального сервера: чат, изменения
  значков, состав разных кланов, отсутствие клана, группы, вход/роспуск и Training.
- Оригинальный x86 reader списка и оба getters проверены с четырьмя комбинациями
  нулевых и положительных ID. UI и управляемые строки в этой проверке изолированы.
