# Ремонт складскими наборами — 20.10.2026

Установлено на хостинг. Штатная команда ПКМ → «Починить» (C2/03) для предмета
бойца теперь сначала использует ремкомплекты из доступного личного склада.
Клиент обновлять не требуется. Переносить наборы в рюкзак больше не нужно.

«Очки починки» остаются суммой текущего ресурса реальных наборов 17/18/19.
Ремонт расходует эту прочность по порядку ID. При необходимости используются
несколько наборов; израсходованные наборы удаляются. При недостатке ресурса
вещь ремонтируется частично. Прежняя формула потери максимальной прочности
сохранена и применяется один раз к общей затрате ресурса команды.
Наборы других городов, других аккаунтов и кланового склада не расходуются;
legacy и overflow соответствуют доступной области существующего счётчика.
Стопка одинаковых наборов при частичном расходе разделяется с выделением
нового ID и сохранением города и остальных единиц.

Изменение инвентаря, списание наборов, аудит, достижение и подготовка ответов
входят в одну SQLite-транзакцию. Ответ включает инвентарь, склад 6A, счётчик
C8/39 и прежнее сообщение об успехе. Для 6A применяется штатное длинное
обрамление, как при переносе предметов. Повтор полного ремонта ничего
не списывает. При отсутствии складских наборов сохранён ремонт набором
из рюкзака; ручной выбор набора и боевой ремонт остаются прежними.

Поставка подготовлена поверх свежего read-only снимка VPS. Изменены только
`tio/repair.py` и ветвь отправки ответа в `tools/loopback_exchange.py`.
Перед установкой: подключений игроков и сохранённых боёв не было.
Резервные копии кода, конфигурации и SQLite:
`/root/tio-before-game-operations-repair-from-warehouse-20261020`.
Все 172 таблицы сохранены, 26 исходных аккаунтов сохранены, SQLite — `ok`,
служба `tio-server` активна. Локальная база игроков не загружалась.

Проверено 76 автоматических сценариев на изолированной копии текущего
runtime VPS: новый ремонт, прежний ремонт/износ, склад, переносы, города,
конкурентные запросы, откат и проекция ресурсов. Один исторический тест аренды
с оплатой Gold исключён: действующий до изменения хостинг принимает аренду
только за кредиты; исходный неудачный запуск и причина отражены в журнале
работы. Правила аренды не изменялись.

Два отдельных исключённых из рейтингов QA-аккаунта проверены через публичный
игровой TLS: 9550 → 9259 после ремонта 50/350 → 341/341; ресурс первого набора
600 → 309. Следующий ремонт расходует несколько наборов, удаляет первый и
оставляет 247 во втором. Последний ремонт при нехватке очков расходует весь
остаток, удаляет наборы и восстанавливает вещь частично. Другой аккаунт и
остальные шесть ресурсов не изменяются. Повтор полного ремонта не списывает
очки. Повторный вход подтверждает сохранение вещей и расхода наборов.
Это автоматизированные протокольные клиенты; графические клики ПКМ в этой
поставке отдельно не проверялись.
