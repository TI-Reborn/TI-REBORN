## Проверенная цепочка моделей

`C:\TIO-Godot\tools\mdjx_to_glb.py` переводит оригинальные `chr_man_head.mdjx` и
`chr_man_body.mdjx` с их JPEG-текстурами в glTF (`.glb`). Godot импортировал обе модели
и отрисовал их рендером Vulkan с правильными текстурами. Пока без скелета и анимаций;
оси оригинала и Godot различаются (модель повёрнута спиной), это учтём в конвертере.

## Предлагаемая структура: отдельные сборки

| Сборка | Содержимое | Зависит от Godot |
|---|---|---|
| `Tio.Network` | Шифрование, пакеты, сессия; перенос из Unity | Нет |
| `Tio.Battle` | Состояние боя на клиенте, подсказки урона и точности по формулам клиента (`MISSES.md`, `ENHANCEMENT.md`, `ARMOR_AUDIT_20261029.md`) | Нет |
| `Tio.Content` | Чтение каталогов предметов, умений, локализации | Нет |
| Конвейер ресурсов | Python-инструменты в `tools/`: MDJX/ADJX → glTF, текстуры → PNG, карты → сцены. Работает офлайн, в игру не входит | — |
| Проект Godot | Сцены, интерфейс, шейдеры (маски цвета брони `mask_1`), ввод | Да |

Каждая сборка без Godot тестируется отдельно, как сервер.
