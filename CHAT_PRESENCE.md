# Списки игроков во вкладках чата

29 сентября 2026. Серверное исправление для исходного клиента, без изменения DLL.

## Поведение

| Вкладка | Список и получатели сообщений |
| --- | --- |
| Глобальный (12) | Все подключённые персонажи сервера, включая находящихся в пути |
| Локация (0) | Подключённые персонажи текущей локации |
| Торговля (6) | Тот же локальный состав, отдельная переписка |
| Помощь (8) | Тот же локальный состав, отдельная переписка |
| Приватный (1) | Личный собеседник; существующая адресная доставка сохранена |
| Клан / Альянс | Членство и соответствующие каналы ещё не восстановлены; общий онлайн сюда не подставляется |

Отправленное сообщение клиент отображает локально. Сервер рассылает его остальным
адресатам и не отправляет второй экземпляр автору; правило действует также для
кланового и альянсового чатов. «Помощь» использует обычный пакет канала 8 с
текстом UTF-16LE.

Список содержит имя, уровень и статус боя из серверного состояния. Оформление,
сортировку и действия по нику выполняет штатный клиент. Вход, выход, смена
локации, уровня и статуса обновляют списки. Во время путешествия локальные
списки пусты. Отключённые аккаунты и боты не считаются присутствующими игроками.
Все соединения получают обновления через собственные серверные потоки.

Поддержанные локации: Reservation (3), Miner's Town (9), четыре шахты (13–16),
Shooting Range (17). Исправление не добавляет ещё не реализованные города.

## Основания

[Оригинальное руководство, печатная с. 13](https://web.archive.org/web/20120425132848id_/http://ti.ggeek.ru:80/files/TIO_manual.pdf)
различает локацию, торговлю, помощь, приватный, клановый и альянсовый чаты.
Локальная копия: `reports/chat-presence/TIO_manual.pdf`; просмотренная страница:
`reports/chat-presence/manual-chat.png` (страница PDF 14).
Руководство прямо ограничивает локационный чат текущей локацией, но не задаёт
географию торговли/помощи. Их общий состав подтверждён более новым клиентом.

В исходном `silver.dll` (SHA-256
`a73396748ea5c3530157db53592a9f3e04744592c3711f38d40d4877b785de11`):

- Диспетчер `7d02d8`: C7/02 → `7cffb0`, записи глобального списка.
- 4F → `7cfd78`: запись передаётся через `a017c8` по очереди каналам 0, 6, 8.
- 51 → `7cff94`: очищает списки этих же каналов через `a01ef4`.
- C7/01 не содержит выбранного канала; сервер отвечает обоими списками.
- Формат записи одинаков: id u32, имя ANSI-Z, уровень u8, герб u32,
  альянс u32, статус u8, ранг u32, дилер u8; число записей u8.

Раньше сервер отправлял только C7 и ограничивал его локацией. Теперь передаёт
C7/04 + C7/02 для глобального списка и 51 + 4F для трёх локальных вкладок.
Сообщения торговли и помощи также ограничены локацией, чтобы список отражал
их аудиторию. Снимки заменяют устаревшую очередь, не удаляя сообщения чата.

## Проверки и установка

- 8 модульных тестов: состав, изоляция, статус, путешествие, все семь локаций,
  ограниченные очереди, личные сообщения.
- 2 интеграционных теста с отдельными зашифрованными TCP-соединениями:
  два/три аккаунта, реальный запрос перехода 1B, вход, выход, обновление списков.
- `tools/verify_presence_native.py` исполняет обработчики исходного DLL через
  Unicorn: C7, 4F, 51. Строковые функции и интерфейс заменены заглушками;
  это подтверждение протокола, а не визуальная проверка окон игры.
- `tools/verify_hosted_chat_presence.py` проверяет публичный сервер тремя
  свежими QA-аккаунтами. Для всех локаций используются позиции только этих
  аккаунтов; отдельно выполняется обычный переход Reservation → Miner's Town.
  Результат: `reports/chat-presence/hosted-verification.json`.

Проверка хостинга завершилась успешно (`passed: true`): все семь локаций,
аудитория четырёх каналов, переход, отключение и повторный вход. QA-соединения
закрыты; итоговая проверка `systemctl is-active tio-server` вернула `active`.
Это сетевые клиенты протокола, не три запущенных графических клиента.

Обновление: `tools/deploy_chat_presence_remote.py`, два серверных файла с
проверкой SHA-256 до/после. Сохранены удалённая SQLite-база, предыдущие код и
конфигурация: `/root/tio-before-chat-presence-h14xpyt_`. Все 42 существовавшие
таблицы были неизменны после установки. Служба `tio-server` прошла preflight и
запущена. Подробности: `reports/chat-presence/deployment.json`.

Визуальный обход вкладок не завершён: инструмент Windows не предоставляет
целевое окно `ti.exe` (ошибка `launched app did not expose a targetable window`).
Нажать сохранённый вход не удалось. Проверка оконным запуском также не помогла;
исходная настройка полноэкранного режима возвращена. Работа кланового,
альянсового и боевого чатов не является результатом этого исправления.

## Исправление повторной доставки — 12 октября 2026

В общем сообщении автор исключён из списка сетевых получателей: штатный клиент
уже добавляет его текст в свой список сообщений. Проверки для каналов Location,
Trade, Help и Global подтверждают по одному пакету получателю и отсутствие
эхо-пакета автору. Клановый и альянсовый маршруты проверяются отдельно.

Сетевой QA на VPS выполняется двумя существующими QA-аккаунтами, без GUI-клиента;
онлайн-время аккаунтов восстанавливается к снятому перед тестом значению.
Подробные результаты и резервная копия установки: `reports/chat-echo-20261012/`.
Пакет канала Help проверен по содержимому UTF-16LE, но графическое отображение
«только запятые» нельзя подтвердить без доступного окна игрового клиента.
