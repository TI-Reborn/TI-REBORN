# Исправление «Получаю вещи…»

Кнопка арены проверяет отдельный каталог предметов, а не личный инвентарь.
Оригинальный silver.dll (SHA256 a73396748ea5c3530157db53592a9f3e04744592c3711f38d40d4877b785de11):
городской обработчик 85b828 показывает m1108, пока массив ac4a9c пуст.
C6/18 RECV_TokenGearsInfo, обработчик 953ec8: u32 количество и u32 ID шаблонов;
обработчик записывает массив и восстанавливает m135 («Бои»).

Сервер отправляет реальные поддерживаемые оружие и броню из магазина после
C2S 50/<текущий город>, когда асинхронное открытие города создало кнопку.
Повторные C6/02 и C6/20 также обновляют каталог перед рейтингом. Чужой город
и запросы во время боя не вызывают отправку городского каталога.
Каталог не выдаёт предметов, не меняет инвентарь, деньги и рейтинг. Рейтинговые
бои по-прежнему используют сохранённую экипировку без оплачиваемых замен.

Проверки: tests/test_arena_gears.py (формат, шаблоны, два TCP аккаунта,
повторное открытие, повторный вход); tools/verify_arena_gears_native.py
(оригинальный x86 диспетчер, чтение всех ID, смена ключа подписи и отсутствие
ветки загрузки). UI вызовы в Unicorn явно подменены; это не визуальная проверка.
