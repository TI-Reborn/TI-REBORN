# Остановка при обнаружении противника

Сервер проверяет обзор на каждой клетке маршрута. Если движущийся боец
открывает живого противника, не видимого его команде в начале команды,
маршрут заканчивается на этой клетке. Клиент получает только пройденный путь.
AP списываются только за выполненные шаги; ход и его таймер не переключаются
и не сбрасываются. Продолжить движение можно новым нажатием.

Учитываются радиус обзора, стены и общая видимость команды. Союзники,
погибшие и уже видимые враги остановки не вызывают. Правило действует
в общей модели боя, включая движение ИИ. Вся входная команда проверяется
до изменения состояния: недопустимый маршрут целиком отклоняется.

Это правило по запросу пользователя. Подтверждение именно автоматической
остановки в доступных выдержках оригинального руководства не найдено:
https://ti.ggeek.ru/files/TIO_manual.pdf
Полный PDF при проверке был недоступен. Историческая точность не заявляется.

## Установка

В Windows PowerShell:

```powershell
scp C:\TIO-emulator\data\tio-movement-contact.tar.gz C:\TIO-emulator\deploy\install_movement_contact.sh root@185.184.42.88:/root/
```

В терминале VPS после выхода игроков из боя:

```bash
bash /root/install_movement_contact.sh
```

Установщик сохраняет базу и прежний файл, перезапускает сервер и при ошибке
возвращает прежний код. Клиент менять не требуется. VPS автоматически
из этой задачи не обновлялся.

## Проверка в игре

Проложить длинный путь мимо скрытого врага. Боец должен остановиться,
когда враг появился, с оставшимися AP. Повторное нажатие должно продолжить
движение. Проверку анимации и отображения AP оригинальным клиентом на VPS
ещё нужно выполнить.
