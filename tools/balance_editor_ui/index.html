МАСТЕРСКАЯ БАЛАНСА

Изменяйте. Сравнивайте. Проверяйте.

  1. Создайте профиль на основе текущих локальных каталогов.
  2. Выберите предмет, измените параметры и проверьте график.
  3. Сохраните профиль. Его можно загрузить снова или передать как JSON.
  4. Экспортируйте ZIP с каталогами кандидата и списком изменений.

Экспорт предназначен для проверки. Для применения в игре отдельно нужны сверка хостинга, клиентских данных и проверка multiplayer. Кнопки публикации здесь нет.
