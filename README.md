# TI REBORN — сервер

Исходники синхронизированы **24 октября 2026 года** с установленным кодом хостинга:
контракты и их нативный интерфейс, премиум и антиопыт, общие склады,
скорость перемещения и предыдущие игровые исправления.
Добавлены чистые исходники опубликованного лаунчера 0.1.33.
[Состав последнего обновления и проверки](docs/HOSTED_SYNC_20261024.md).
Предыдущие обновления Training Base, кланов, склада и производительности сохранены.
Адресная конфигурация VPS и данные игроков в репозиторий не входят.

## Состав

| Путь | Назначение |
| --- | --- |
| `server/` | Запуск, аккаунты, многопользовательские сессии, серверные сервисы и HTTP API |
| `tio/` | Правила игры, состояние, экономика, SQLite-хранилища |
| `tio/protocol/` | Чтение и запись бинарных пакетов клиента |
| `config/` | Каталоги, баланс, карты, безопасная локальная конфигурация |
| `tools/` | Runtime-сцены, диагностика, подготовка выпусков и исторические исследовательские утилиты |
| `evidence/` | Только пять обязательных каталогов/фикстур runtime, перечисленных в `server/runtime.py` |
| `registration/` | Дополнительный Flask-сервис регистрации и мост к игре |
| `launcher/` | Исходники лаунчера 0.1.33 и его проверенные ресурсы; .NET 10, Windows Forms |
| `deploy/` | Упаковка сервера, резервное копирование и шаблоны служб |
| `tests/` | Автоматические проверки; часть расширенных тестов требует внешних ресурсов |
| `.github/` | CODEOWNERS, шаблон PR и CI без доступа к хостингу |

Python **3.11+**. Игровому серверу достаточно стандартной библиотеки.
Запускать из корня checkout: `python -m server --check`.
Для разработки нескольких аккаунтов используйте инструкцию запуска ниже по ссылке;
исторический `config/server.toml` включает диагностический режим одного аккаунта.

Базы игроков, пароли, ключи, `.env`, отчёты, дампы памяти, исполняемые файлы клиента,
сборки лаунчера, Unity-проект и сайт Next.js в эту передачу не включены.
Исходники этих отдельных компонентов остаются у владельца. Ссылки на них в старых
документах описывают исходную рабочую среду и могут не открываться в этом репозитории.

Старый README сохранён в [README_HISTORY.md](README_HISTORY.md): его статусы исторические.
